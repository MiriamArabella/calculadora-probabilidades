Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación web titulada “Calculadora de Probabilidades”, la cual permite calcular e interpretar valores asociados a las principales distribuciones de probabilidad utilizadas en estadística: Binomial, Poisson, Exponencial y Normal (Z).

Cada sección incluye teoría breve, fórmula, campos de entrada, resultados numéricos, interpretación y una gráfica dinámica que muestra visualmente los cálculos realizados.

Objetivo

Aplicar los conceptos teóricos de probabilidad mediante el uso de herramientas tecnológicas, mostrando cómo la programación puede facilitar el aprendizaje estadístico a través del desarrollo de interfaces interactivas.

Tecnologías utilizadas

  • HTML5 para la estructura de las páginas.
  • TailwindCSS para los estilos rápidos y adaptables.
  • JavaScript para los cálculos e interactividad.
  • Chart.js para las gráficas estadísticas.
  • Visual Studio Code como entorno de desarrollo.
